# Задача 0000000002 — добавить CodeRabbit CLI

Статус: завершена 2026-10-15.

Связанные документы: [контекст](context.md), [решения](adr.md).

## Требования

Установить закреплённую версию CodeRabbit CLI в Docker-образ для AMD64 и ARM64.
Обе команды `coderabbit` и `cr` должны быть доступны в PATH. Сборка должна
проходить без авторизации, а README — описывать запуск и вход после сборки.
Сохранить Codex в качестве entrypoint и существующий механизм обновления npm CLI.
Не выпускать образ и не менять VERSION в рамках этой задачи.

## Критерии приёмки

- [x] Версия задана через `ARG CODERABBIT_VERSION`; используется официальный
  версионный установщик с проверкой подписи и поддержкой обеих архитектур.
- [x] Установка в `/usr/local/bin` не требует интерактивного входа.
- [x] README содержит команды запуска, авторизации и ревью.
- [x] Пройдены доступные lint, build, smoke и scan; ограничения точно записаны.
- [x] Проверены относительные ссылки и `git diff --check`.

## Решения реализации

В Dockerfile добавлены `openssl` и `unzip`, необходимые официальному установщику.
Установщик и архив выбираются по одной версии `0.9.0`; установщик проверяет
подписанный манифест и контрольные суммы, распознаёт архитектуру и создаёт `cr`.
`CR_CLI_SKIP_LOGIN=1` действует только при установке. Сборка запускает обе команды
с `--version`, чтобы обнаружить отсутствие команды или неработающий бинарник.

## Проверки

- `task test`: 53 теста прошли; существующий парсер принимает дополнительный ARG,
  а хеш состава учитывает полный Dockerfile.
- Hadolint 2.12.0 через Docker с `--failure-threshold error` из `task lint`:
  exit 0. Локальный бинарник Hadolint отсутствует; использован образ
  `hadolint/hadolint:v2.12.0`. Остались предупреждения о pinning и стиле:
  DL3008, DL3003, DL3059, DL3027, SC1091.
- `task build`: exit 0, собран локальный `docker-codex:dev` для Linux ARM64.
- Проверки через `docker run --rm --network none`: стандартный entrypoint
  вернул `codex-cli 0.154.0`; entrypoint `coderabbit` и `cr` каждый вернул `0.9.0`.
  Подтверждена ссылка `/usr/local/bin/cr -> /usr/local/bin/coderabbit`.
- По `auth login --help` и `review --help` закреплённого CLI проверены команды
  README: авторизация по API key, выбор EU и обычный `review`. Текстовый вывод
  используется по умолчанию; устаревшего `--plain` в примере нет.
- `task scan`: exit 0 через временную обёртку Trivy 0.76.0 в Docker, поскольку
  локальный бинарник отсутствует. Кешированный JSON-проход уточнил итог: 365 HIGH
  и 15 CRITICAL записей, 168 уникальных CVE во всём образе. По целям: Debian —
  345 HIGH / 14 CRITICAL; Node.js — 9 / 1; Docker Buildx — 7 / 0; Compose — 4 / 0.
  Это успешное выполнение сканера, а не отсутствие уязвимостей: текущий `task scan`
  не устанавливает ненулевой exit code за находки. Сравнение с предыдущим образом
  не выполнялось; эти числа не приписываются новой зависимости. Предупреждения
  secret scanner касались больших файлов npm cache.
- Относительные ссылки README и трёх документов задачи разрешаются;
  `git diff --check` прошёл.

Локально проверена ARM64. AMD64 поддерживается официальным установщиком, но отдельная
локальная AMD64-сборка не выполнялась; обе команды с `--version` включены в Dockerfile
и будут проверяться при каждой целевой сборке. Реальное ревью с авторизацией
не выполнялось: учётные данные для проверки установки не требуются.
