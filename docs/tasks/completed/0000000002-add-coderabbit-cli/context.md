# CodeRabbit CLI в docker-codex

Пользователь попросил добавить CodeRabbit CLI в образ. Основная команда образа —
Codex; CodeRabbit должен быть доступен из рабочей оболочки и другим агентам по PATH.

CodeRabbit распространяет отдельные ZIP-архивы для Linux x64 и ARM64, а не npm-пакет.
На 2026-10-15 официальный стабильный релиз — `0.9.0`. Его установщик доступен по
версионному URL и проверяет подпись манифеста и SHA-256 до распаковки Linux-архива.
`cr` — короткое имя команды `coderabbit`, которое создаёт тот же установщик.

Существующая автоматизация обновляет три npm CLI. Новый ARG не меняет её список
пакетов, а изменение Dockerfile учитывается в составе релиза. Версия CodeRabbit
обновляется вручную.
