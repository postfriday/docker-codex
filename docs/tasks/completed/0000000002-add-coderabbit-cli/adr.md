# Устанавливать CodeRabbit официальным версионным установщиком

CodeRabbit CLI не входит в список npm-инструментов проекта. Используем официальный
`releases/${CODERABBIT_VERSION}/install.sh`, а не скрипт из изменяемого latest:
он сохраняет проверку подписи Linux-релиза и поддерживает x64/ARM64 без дублирования
логики выбора архива и проверки манифеста в Dockerfile.

Добавляем необходимые `openssl` и `unzip` к apt-зависимостям. Устанавливаем команды
в `/usr/local/bin`, чтобы они были доступны независимо от домашнего каталога.
Переменная `CR_CLI_SKIP_LOGIN=1` отключает вход только на этапе установки; учётные
данные не нужны для сборки. Версия CodeRabbit обновляется вручную: расширение
автоматизации npm другим источником версий выходит за рамки запроса.
