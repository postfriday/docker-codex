# Выпуск docker-codex

Образ объединяет Codex, OpenCode и Claude Code. Версии инструментов и версия образа имеют независимую нумерацию. См. [спецификацию задачи](task.md) и [архитектурные решения](adr.md).

## Language

**Версия CLI**:
Версия отдельного инструмента, включённого в образ: Codex, OpenCode или Claude Code.
_Avoid_: Версия образа при обозначении версии одного инструмента.

**Версия образа**:
Версия общего выпуска docker-codex, объединяющего инструменты и среду их выполнения.
_Avoid_: Версия Codex при обозначении общего выпуска.

**Автоматическое обновление CLI**:
Переход на более новую patch- или minor-версию инструмента без ручного подтверждения. Переход на новый major требует ручного рассмотрения.

**Кандидат выпуска**:
Конкретный собранный образ, предназначенный для проверки и последующей публикации как версия docker-codex. При повторных попытках выпуска используется этот же образ.

**Незавершённый выпуск**:
Начатый выпуск версии docker-codex, для которого ещё не выполнены все условия завершения. Его продолжение имеет приоритет перед началом следующего автоматического выпуска.

**Завершённый выпуск**:
Выпуск, для которого успешно выполнены проверки обеих архитектур, сохранены отчёты и подтверждение происхождения, а итоговые теги образа назначены проверенному кандидату.

**Отменённый выпуск**:
Выпуск, продолжение которого вручную прекращено. Его номер остаётся использованным, а кандидат сохраняется для диагностики.

**Состав выпуска**:
Версии трёх CLI и рецепт их установки вместе со средой выполнения. Исправление рецепта при прежних версиях CLI образует другой состав.

**Зарезервированный выпуск**:
Выпуск с закреплёнными номером и исходниками, который ещё не завершил проверку и публикацию. Резервирование номера не означает доступность готового образа.

**Попытка выпуска**:
Одно выполнение продолжения конкретного выпуска. Несколько попыток относятся к одному номеру и одному сохранённому кандидату.

**Базовый выпуск**:
Существующий выпуск, относительно которого автоматизация начинает отслеживать новые составы. Его регистрация не означает прохождение проверок, добавленных позже.
